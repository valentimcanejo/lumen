# LUMEN — UX Flows

## Onboarding

1. Welcome
2. Idioma (PT/EN/ES)
3. Objetivos (1–3)
4. Tempo diário (5/10/15)
5. Seleção de 3 trilhas iniciais
6. Notificações (opcional)
   → Home (Dose do dia)

## Tabs

- Home (Dose)
- Trilhas
- Biblioteca
- Perfil

## Sessão diária (Home Stack)

1. LessonScreen (texto + ouvir)
2. CardsScreen (flip + auto-avaliação)
3. QuizScreen (feedback imediato)
4. SummaryScreen (resumo + streak + extra)

## Explorar

- Trilhas → lista de lessons
- Buscar por tags/assuntos
- Salvar para Biblioteca

## Premium (IA)

- Paywall ao tocar em recursos IA
- Benefícios: tutor IA, quizzes personalizados, revisões avançadas
