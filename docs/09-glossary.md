# LUMEN — Glossary

- Dose do dia: sessão curta diária (5–15 min)
- Pack: arquivo JSON com conteúdo da sessão (cacheável)
- Trilhas (tracks): áreas temáticas (Geopolítica, Filosofia etc.)
- Lesson: mini-aula principal
- Cards: reforço rápido
- Quiz: verificação e fixação
- Spaced repetition: revisão inteligente com intervalos
- Shield: proteção de streak (1 por semana, ex)
